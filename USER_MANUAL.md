## Welcome

**Last Updated:** 2025-11-12

### What is JSR Task Management?

JSR Task Management is a comprehensive productivity platform designed to help teams:

- ✅ **Manage Tasks**: Create, assign, and track work tasks
- 🐛 **Track Bugs**: Report and resolve software bugs
- 📅 **Apply for Leave**: Submit and approve leave applications
- 🏠 **Request WFH**: Apply for work-from-home days
- 💬 **Collaborate**: Share updates via social feed
- ⏱️ **Track Time**: Monitor time spent on tasks and bugs
- 📊 **View Reports**: Analyze productivity and progress

### Who Can Use It?

- **Employees (Amtariksians)**: Manage your tasks, report bugs, apply for leave
- **Managers**: Approve leave/WFH, assign tasks, monitor team progress
- **Top Management**: View organization-wide data and reports
- **Administrators**: Full system access and configuration

### How to Access

- **Web App**: https://task.amtariksha.com
- **Mobile App**: Download APK and install on Android device
- **Credentials**: Provided by your administrator

## Task Management

**Last Updated:** 2025-11-12

### Viewing Tasks

#### Task List

1. **Navigate to Tasks**
   - Click "Tasks" in top navigation
   - View all your tasks

2. **Filter Tasks**
   - **Status**: Yet to Start, In Progress, Completed, Closed
   - **Priority**: U&I, U&NI, NU&I, NU&NI
   - **Assigned To**: Filter by assignee
   - **Project**: Filter by project

3. **Sort Tasks**
   - By due date (default)
   - By priority
   - By status
   - By creation date

#### Task Details

Click on any task to view full details:

- **Task ID**: Unique identifier (e.g., TSK-001)
- **Name**: Task title
- **Description**: Full task description
- **Assigned To**: Who is working on it
- **Assigned By**: Who created the task
- **Support**: Team members providing support
- **Start Date**: When task starts
- **End Date**: When task is due
- **Priority**: Urgency level
- **Status**: Current status
- **Estimated Hours**: Expected time to complete
- **Actual Hours**: Time tracked via timer
- **Project**: Associated project
- **Remarks**: Additional notes
- **Difficulties**: Challenges encountered
- **Checklists**: Sub-items to complete
- **Activity Log**: History of changes

### Creating a Task

**Who Can Create:** All users

1. **Click "Create Task" Button**
2. **Fill in Details:**
   - **Description**: What needs to be done
   - **Assigned To**: Select employee(s)
   - **Support**: Select support team (optional)
   - **Start Date**: When to start
   - **End Date**: When it's due
   - **Priority**: Select priority level
   - **Estimated Hours**: How long it will take
   - **Task Type**: Normal or Recursive
   - **Project**: Select project (optional)

3. **Click "Create"**
4. **Task Created**
   - Unique task ID generated
   - Assigned users receive email notification
   - Task appears in task list

### Updating a Task

**Who Can Update:** Assigned users, managers, admins

1. **Open Task Details**
2. **Click "Edit" Button**
3. **Update Fields:**
   - Change status
   - Update remarks
   - Add difficulties
   - Modify dates
   - Update estimated/actual hours

4. **Click "Save"**
5. **Changes Logged**
   - Activity log updated
   - Notifications sent if status changed

### Using the Timer

**Purpose:** Track actual time spent on tasks

#### Start Timer

1. **Open Task Details**
2. **Click "Start Timer" Button**
3. **Timer Starts**
   - Timer shows elapsed time (HH:MM:SS)
   - Updates every second
   - Only one timer can run at a time

**Note:** Timer button only appears for tasks with status other than "Closed" or "Resolved"

#### Pause Timer

1. **Click "Pause Timer" Button**
2. **Timer Pauses**
   - Elapsed time saved
   - Can resume later

#### Resume Timer

1. **Click "Resume Timer" Button**
2. **Timer Continues**
   - Picks up where it left off

#### Stop Timer

1. **Click "Stop Timer" Button**
2. **Timer Stops**
   - Total time added to actual hours
   - Timer session saved for audit trail
   - Can start new timer session later

### Task Checklists

**Purpose:** Break down tasks into smaller steps

1. **Open Task Details**
2. **Scroll to "Checklists" Section**
3. **Add Checklist Item:**
   - Click "Add Item"
   - Enter description
   - Assign to team member (optional)
   - Set status

4. **Mark as Complete:**
   - Check the checkbox
   - Item marked as completed

5. **View Progress:**
   - See percentage of items completed
   - Track overall task progress

## Bug Tracking

**Last Updated:** 2025-11-12

### Viewing Bugs

#### Bug List

1. **Navigate to Bugs**
   - Click "Bugs" in top navigation

2. **Filter Bugs**
   - **Status**: Open, In Progress, Resolved, Closed
   - **Severity**: Critical, High, Medium, Low
   - **Category**: UI, Backend, Database, etc.
   - **Assigned To**: Filter by assignee
   - **Reported By**: Filter by reporter

3. **Sort Bugs**
   - By severity (default)
   - By reported date
   - By status

#### Bug Details

Click on any bug to view full details:

- **Bug ID**: Unique identifier (e.g., BUG-001)
- **Title**: Bug summary
- **Description**: Detailed description
- **Category**: Bug category
- **Severity**: How critical it is
- **Priority**: Urgency level
- **Status**: Current status
- **Assigned To**: Developer working on it
- **Reported By**: Who found the bug
- **Reported Date**: When it was reported
- **Resolved Date**: When it was fixed
- **Attachments**: Screenshots, logs, videos
- **Platform**: Web, Mobile, API
- **Environment**: Dev, Staging, Production
- **Development Checklists**: Fix steps
- **Activity Log**: History of changes

### Reporting a Bug

**Who Can Report:** All users

1. **Click "Report Bug" Button**
2. **Fill in Details:**
   - **Title**: Brief summary
   - **Description**: Detailed description of the issue
   - **Category**: Select category (UI, Backend, etc.)
   - **Severity**: How critical is it?
     - **Critical**: System down, data loss
     - **High**: Major feature broken
     - **Medium**: Feature partially broken
     - **Low**: Minor issue, cosmetic
   - **Platform**: Where did it occur? (Web, Mobile, API)
   - **Environment**: Dev, Staging, or Production
   - **Steps to Reproduce**: How to recreate the bug
   - **Expected Behavior**: What should happen
   - **Actual Behavior**: What actually happens
   - **Attachments**: Upload screenshots, logs, videos

3. **Click "Submit"**
4. **Bug Created**
   - Unique bug ID generated
   - Assigned developer receives email
   - Bug appears in bug list

### Adding Attachments

**Supported Files:** Images (PNG, JPG), Videos (MP4), Logs (TXT), Documents (PDF)
**Max Size:** 50MB per file

1. **Open Bug Details**
2. **Click "Add Attachment" Button**
3. **Select File(s)**
   - Choose from device
   - Multiple files supported

4. **Upload**
   - Files upload to AWS S3
   - URLs saved to bug record
   - Attachments visible to all users

5. **View Attachments**
   - Click thumbnail to view full size
   - Download if needed

### Updating Bug Status

**Who Can Update:** Assigned developer, managers, admins

**Status Workflow:**
```
Open → In Progress → Resolved → Closed
  ↓                      ↓
  └──────────────────────┴──→ Reopened
```

1. **Open Bug Details**
2. **Click "Edit" Button**
3. **Change Status:**
   - **In Progress**: Started working on fix
   - **Resolved**: Fix completed, ready for testing
   - **Closed**: Verified and closed
   - **Reopened**: Issue persists, needs more work

4. **Add Remarks**
   - Explain what was done
   - Describe the fix

5. **Click "Save"**
6. **Notifications Sent**
   - Reporter notified of status change
   - Activity log updated

### Development Checklists

**Purpose:** Track fix steps for complex bugs

1. **Open Bug Details**
2. **Scroll to "Development Checklists"**
3. **Add Checklist Item:**
   - Click "Add Item"
   - Enter description (e.g., "Fix backend API", "Update frontend", "Write tests")
   - Assign to developer
   - Set status

4. **Mark as Complete:**
   - Check the checkbox
   - Item marked as completed

## Leave Management

**Last Updated:** 2025-11-12

### Leave Types

- **Sick Leave**: For illness or medical appointments
- **Casual Leave**: For personal reasons
- **Earned Leave**: Vacation days earned
- **Maternity Leave**: For new mothers
- **Paternity Leave**: For new fathers
- **Unpaid Leave**: Leave without pay
- **Compensatory Off**: Compensation for overtime

### Applying for Leave

1. **Navigate to Leave**
   - Click "Leave" in top navigation

2. **Click "Apply for Leave" Button**

3. **Fill in Details:**
   - **Leave Type**: Select type
   - **Start Date**: First day of leave
   - **End Date**: Last day of leave
   - **Total Days**: Auto-calculated (excluding weekends)
   - **Reason**: Why you need leave

4. **Click "Submit"**

5. **Application Submitted**
   - Unique leave ID generated (LV-001)
   - Manager receives email notification
   - Status set to "Pending"

### Viewing Leave Status

1. **Navigate to Leave**
2. **View Your Applications:**
   - **Pending**: Awaiting manager approval
   - **Approved**: Manager approved
   - **Rejected**: Manager rejected (with reason)
   - **Cancelled**: You cancelled the application

3. **Click on Application** to view details:
   - Leave dates
   - Reason
   - Approval status
   - Approved/rejected by
   - Rejection reason (if rejected)

### Cancelling Leave

**Who Can Cancel:** Applicant (before approval), managers, admins

1. **Open Leave Application**
2. **Click "Cancel" Button**
3. **Confirm Cancellation**
4. **Leave Cancelled**
   - Status changed to "Cancelled"
   - Manager notified

### Leave Balance

View your available leave balance:

1. **Navigate to Leave**
2. **View "Leave Balance" Section:**
   - **Sick Leave**: X days remaining
   - **Casual Leave**: X days remaining
   - **Earned Leave**: X days remaining

**Note:** Balance updates automatically when leave is approved

## FAQ

**Last Updated:** 2025-11-12

### General Questions

**Q: How do I reset my password?**
A: Contact your administrator. Password reset feature coming soon.

**Q: Can I use the app on iOS?**
A: iOS app is in development. Currently available for Android and web.

**Q: How do I report a problem with the system?**
A: Report a bug using the Bug Tracking feature, or contact support.

### Task Questions

**Q: Can I assign a task to multiple people?**
A: Yes! Tasks support multiple assignees. Select all team members when creating/editing.

**Q: What's the difference between "Assigned To" and "Support"?**
A: "Assigned To" are primary owners. "Support" are team members helping out.

**Q: Why can't I see the timer button?**
A: Timers are hidden for tasks with status "Closed" or "Resolved".

**Q: Can I edit a task after it's created?**
A: Yes, if you're assigned to it, a manager, or admin.

### Bug Questions

**Q: What severity should I choose?**
A:
- **Critical**: System down, data loss, security issue
- **High**: Major feature broken, many users affected
- **Medium**: Feature partially broken, workaround exists
- **Low**: Minor issue, cosmetic problem

**Q: Can I attach multiple files to a bug?**
A: Yes, up to 50MB per file. Supported: images, videos, logs, PDFs.

**Q: Who can see my bug reports?**
A: All team members can view all bugs for transparency.

### Leave Questions

**Q: How many days of leave do I have?**
A: Check "Leave Balance" section in Leave page.

**Q: Can I cancel approved leave?**
A: Contact your manager. Only managers can cancel approved leave.

**Q: Why was my leave rejected?**
A: Check the rejection reason in your leave application details.

**Q: Do weekends count as leave days?**
A: No, weekends are automatically excluded from leave calculations.

### Feed Questions

**Q: Can I delete my post?**
A: Yes, click "..." menu on your post → Delete.

**Q: Can I edit a post after publishing?**
A: Yes, click "..." menu → Edit.

**Q: Who can see my posts?**
A: All team members can see all posts (public feed).

**Q: How do I create a private post?**
A: Private posts feature coming soon.

## Troubleshooting

**Last Updated:** 2025-11-12

### Login Issues

**Problem:** Can't login, "Invalid credentials" error

**Solutions:**
1. Verify Employee ID is correct (e.g., AM-0001)
2. Check password (case-sensitive)
3. Clear browser cache and cookies
4. Try different browser
5. Contact administrator to reset password

---

**Problem:** "Network error" when logging in

**Solutions:**
1. Check internet connection
2. Verify URL: https://task.amtariksha.com
3. Try again in a few minutes
4. Contact IT support if persists

### Task/Bug Issues

**Problem:** Can't create task/bug

**Solutions:**
1. Ensure all required fields are filled
2. Check date format (YYYY-MM-DD)
3. Verify you have permission to create
4. Refresh page and try again

---

**Problem:** Timer not working

**Solutions:**
1. Verify task status is not "Closed" or "Resolved"
2. Check if another timer is running (only one at a time)
3. Refresh page
4. Contact support if issue persists

### Mobile App Issues

**Problem:** App crashes on launch

**Solutions:**
1. Uninstall and reinstall app
2. Clear app cache (Settings → Apps → JSR → Clear Cache)
3. Ensure Android version is 8.0 or higher
4. Download latest APK version

---

**Problem:** "Network request failed" error

**Solutions:**
1. Check internet connection
2. Verify app has network permissions
3. Try switching between WiFi and mobile data
4. Reinstall app

### Email Notification Issues

**Problem:** Not receiving email notifications

**Solutions:**
1. Check spam/junk folder
2. Verify email address in profile settings
3. Check notification preferences (Settings → Notifications)
4. Contact administrator to verify email service
