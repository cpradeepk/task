# 📱 JSR Task Management Mobile App - User Guide

**Version**: 1.0.0  
**Platform**: Android  
**Last Updated**: November 11, 2025

---

## 🚀 Getting Started

### Installation

1. **Download APK**: Get the latest `app-debug.apk` from your administrator
2. **Enable Unknown Sources**: Settings → Security → Install unknown apps → Enable for your file manager
3. **Install**: Tap the APK file and follow the installation prompts
4. **Launch**: Open "JSR Task Management" from your app drawer

---

## 🔐 Login

### First Time Login

1. Enter your **Employee ID** (e.g., AM-0001)
2. Enter your **Password**
3. Tap **Login**

### Biometric Login (Optional)

After your first successful login, you can enable biometric authentication:

1. Login with your credentials
2. Go to **Settings**
3. Enable **Biometric Login**
4. Next time, tap **🔐 Login with Fingerprint/Face ID**

## 📊 Dashboard

The dashboard shows:
- **Quick Stats**: Total tasks, bugs, leave applications
- **Quick Actions**: Navigate to different sections
- **Recent Activity**: Latest tasks and bugs

**Navigation**:
- Tap any card to view details
- Use the notification bell (top right) to see alerts
- Swipe down to refresh data

---

## ✅ Tasks

### View Tasks
1. Dashboard → **Tasks**
2. Filter by status, priority, or search
3. Tap a task to view details

### Create Task
1. Dashboard → **Create Task**
2. Fill in:
   - Description
   - Assigned To
   - Start/End Date
   - Priority
   - Estimated Hours
3. Tap **Create Task**

### Update Task
1. Open task details
2. Update status, remarks, or actual hours
3. Tap **Save**

---

## 🐛 Bugs

### View Bugs
1. Dashboard → **Bugs**
2. Filter by status, severity, or category
3. Tap a bug to view details

### Create Bug
1. Dashboard → **Create Bug**
2. Fill in:
   - Title
   - Description
   - Severity (Critical/Major/Minor)
   - Category (UI/API/Backend/etc.)
   - Platform (Web/iOS/Android)
3. Add attachments (optional)
4. Tap **Create Bug**

### Update Bug
1. Open bug details
2. Update status, add comments, or log hours
3. Manage subtasks
4. Tap **Save**

---

## 📰 Feed

### View Posts
1. Dashboard → **Feed**
2. Browse posts from all topics
3. Filter by topic
4. Tap a post to view details

### Create Post
1. Feed → **+ Create Post**
2. Choose content type:
   - Text
   - Link
   - Media
3. Select topics
4. Tap **Post**

### Interact with Posts
- **React**: Tap emoji to add reaction
- **Comment**: Add comments and replies
- **Save**: Bookmark posts for later

---

## 🏖️ Leave Applications

### Apply for Leave
1. Dashboard → **Leave**
2. Tap **+ Apply for Leave**
3. Fill in:
   - Leave Type (Casual/Sick/Earned)
   - Reason
   - From/To Date
   - Half Day (optional)
   - Emergency Contact
4. Tap **Submit**

### View Leave Status
1. Dashboard → **Leave**
2. Filter by status (Pending/Approved/Rejected)
3. Tap to view details

---

## 🏠 WFH Applications

### Apply for WFH
1. Dashboard → **WFH**
2. Tap **+ Apply for WFH**
3. Fill in:
   - WFH Type (Full Day/Half Day)
   - Reason
   - From/To Date
   - Work Location
   - Available Hours
   - Contact Number
4. Tap **Submit**

### View WFH Status
1. Dashboard → **WFH**
2. Filter by status (Pending/Approved/Rejected)
3. Tap to view details

---

## 🆘 Troubleshooting

### App Won't Login
- Check your internet connection
- Verify your Employee ID and password
- Contact your administrator if credentials are correct

### Data Not Loading
- Pull down to refresh
- Check internet connection
- Restart the app

### App Crashes
- Clear app cache: Settings → Apps → JSR Task Management → Clear Cache
- Reinstall the app
- Contact support with error details
